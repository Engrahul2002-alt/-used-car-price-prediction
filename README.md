# 🚗 Used Car Price Prediction

### Machine Learning | Regression | Regularization

## 📌 Project Overview
This project focuses on predicting used car prices using Machine Learning techniques.

The project uses a German used-car dataset containing approximately 15,915 records and 23 features.

## 🎯 Objectives
- Understand the factors affecting used car prices.
- Perform Exploratory Data Analysis (EDA).
- Clean and preprocess real-world data.
- Handle categorical features and outliers.
- Build regression models for price prediction.
- Apply regularization techniques to reduce overfitting.
- Evaluate model performance.

## 📊 Dataset Information
- Total records: 15,915
- Total features: 23
- Target variable: `price`
